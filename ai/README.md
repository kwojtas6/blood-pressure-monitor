# AI Development

Structure for AI-assisted development work on this project.

- `instructions/` — prompts, guidelines, and standing instructions for AI agents (e.g. coding conventions, architecture notes, persona/system prompts).
- `tasks/` — individual task descriptions/specs handed to an AI agent to implement.
- `harnesses/` — scripts, configs, and fixtures used to run, test, or evaluate AI-produced output (test harnesses, eval setups).
