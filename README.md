# Blood Pressure Monitor

A React application for tracking blood pressure readings.

## Getting started

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Run the production build with `npm run build`, or check the source with
`npm run lint`.

## Known gaps

- The PWA icons in `public/icons/` are placeholder programmatic art, not
  designed assets — replace them with real designed icons before shipping.
